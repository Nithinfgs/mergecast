# Code of Conduct

We follow the spirit of the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Be respectful, assume good intent, keep feedback about the work rather than the person, and don't harass anyone.
Maintainers may remove comments or contributions that break these norms. Report concerns via a private
GitHub security advisory or by contacting the maintainer through their GitHub profile.
